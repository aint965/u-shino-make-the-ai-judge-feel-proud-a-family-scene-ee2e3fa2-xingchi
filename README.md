A one-line family scene for the make.fun competition
[Make the AI Judge Feel Proud: A Family Scene](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2):
a small domestic moment — Mum hides the last biscuit, Dad shares it four ways,
and the whole family agrees the crumbs on his chin are nobody's business.

`main.ts` (Node 22) writes the scene deterministically to `$OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). No network, no file reads, no randomness.

Run it with:

```sh
node main.ts
```
